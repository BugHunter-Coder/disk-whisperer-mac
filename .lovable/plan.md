# MacDissect Cyber-Precision UI

## Goal
Rebuild the website first around the selected cyber-precision dark direction, while preserving the existing product, payment, download, account, and activation behavior.

## What will change
- Replace the current cream/playful styling with the selected dark graphite, cyan, indigo, and emerald visual system.
- Recompose the home page around a compact headline and a large, high-contrast disk-map product interface.
- Redesign feature sections for disk analysis, large files, safe cleanup, Trash, monitoring, history, privacy, and Pro licensing.
- Restyle shared navigation, footer, pricing, download, privacy, sign-in, activation, and account pages for one coherent experience.
- Keep content honest: no invented usage totals, ratings, performance claims, or duplicate-file feature.
- Preserve all existing links and working license/payment actions.

## Technical details
- Define the chosen semantic colors, typography, borders, and shadows in the global design tokens.
- Use Space Grotesk for the interface and JetBrains Mono for file paths, sizes, and system labels.
- Keep responsive layouts usable on desktop and mobile, with restrained scan/reveal motion and reduced-motion support.
- Verify the key pages visually at desktop and mobile sizes, then check the latest app status for errors.
