## Short description
MacDissect is a native macOS disk space analyzer. It maps your disk as a treemap or sunburst, lists your largest files, and its Smart Cleanup finds 14 kinds of reclaimable data (Xcode DerivedData, iOS simulators, node_modules, Docker, package caches) and moves only what you pick to the Trash. Scans never leave your Mac.

## Full description
Your Mac says the disk is almost full, and System Settings just says "System Data". MacDissect shows you exactly where the space went.

- Explore: treemap, sunburst and folder list of the same scan. Click to drill in.
- Large Files: every file above the size you pick, biggest first.
- Smart Cleanup (Pro): recognizes 14 categories of reclaimable data, including developer junk like Xcode DerivedData, simulators, node_modules, build output, Docker and package caches. "Select Regenerable" picks only data that rebuilds itself; anything holding your own data is flagged for review.
- History (Pro): size-over-time chart and which folders grew or shrank.
- Monitoring (Pro): free space in the menu bar, low-space alerts, scan at login.
- Live Stats: CPU, memory, battery, network and disk activity.

Safe by design: items go to the Trash so you can restore them, system folders are off-limits, and there is no telemetry. The only network request is license activation.

Native SwiftUI app, signed and notarized by Apple. macOS 14 Sonoma or later, Apple silicon and Intel.
